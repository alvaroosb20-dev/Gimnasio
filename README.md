# Gimnasio Miguel Ángel — web

Web estática (HTML + CSS + JS, sin dependencias) lista para Vercel.

## Publicar en Vercel
1. Sube esta carpeta a un repositorio de GitHub.
2. En Vercel: Add New → Project → importa el repo → Framework: "Other" → Deploy.

## Antes de publicar
- Si el dominio final no es `gimnasio-miguel-angel.vercel.app`, busca y reemplaza esa URL en
  `index.html`, `robots.txt`, `sitemap.xml` y las páginas legales.
- Rellena los campos entre [CORCHETES] de `aviso-legal.html`, `privacidad.html` y `cookies.html`.
- Teléfono extra, email y redes: hay un bloque comentado (EDITAR) en la sección Contacto de `index.html`.
- Servicios, horarios o cuotas: solo añadir cuando el gimnasio los confirme (comentarios EDITAR).
